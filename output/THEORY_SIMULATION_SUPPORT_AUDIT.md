# 明确理论条款的仿真支撑审计

审计范围仅限论文中明确写出的假设、定理和引理；论文未明确要求的性质不纳入本轮结论。

| 明确理论条款 | 仿真证据 | 判定 |
|---|---|---|
| Assumption 1：可控/可观与重构秩 | 两应用模型可控秩和可观测窗口秩分别为 `6/6`、`4/4` | 支撑 |
| 仿射 Wasserstein 内层问题与三项值函数 | Bellman 残差 `< 8.73e-11`；输入/扰动 FOC 残差 `< 4.28e-13` | 支撑 |
| \(P\) 正定性定理 | \(P\) Lyapunov 残差 `< 1.02e-12`；\(\Phi_P\succ0\)、\(P\succ0\)、\(\rho(G)<1\) | 支撑 |
| 缩放稳定化引理 | 非稳定初始策略经缩放后原系统稳定；每次 SDPI 迭代 \(\rho(G)<1\) | 支撑有限实例 |
| \(X\)-LMI 稳定性充要判据 | 稳定实例的 \(X=P_0-\alpha P^*\) 构造和 SDP 均可行；失稳方向只给出数值不可行证据 | 条件性支撑；不是完整 SDP 对偶证明 |
| SDPI 稳定性与聚点结论 | 已记录每次迭代稳定和数值固定点；未穷尽所有满足条件的迭代序列 | 稳定性支撑；聚点结论只能作条件性理论证据 |
| 重构误差定理中的 \(N^{-1/2}\) 项 | 数据驱动重构、输入恒等式和扰动映射斜率约 `-0.47` 至 `-0.51` | 支撑有限样本趋势 |
| 重构误差定理中的扰动窗口残差项 | `od_e5d_reconstruction_bound_audit.md` 显式计入 \(\|\hat T_d\|\|d_{[k-\ell,k-1]}-\bar v_{[\ell]}\|\)，并以独立种子标定 \(C_1\)：Humanoid 48/48、Microgrid 48/48 个 held-out 点满足界；最大比值分别为 `0.3948`、`0.4360` | 支持有限样本包络；不是通用常数证明 |
| 数据驱动局部速率定理中的 \(P,K,p\) 速率 | `od_e5g_rigorous_rate_validation.md`：独立 PE、固定策略、一次评价/改进、低噪声、5 seeds；五个主要斜率均在 `-0.47` 至 `-0.54` 附近 | 在定理声明的良条件 PE/谱隙/Schur 条件下有直接有限样本支撑；不声称适用于任意闭环数据 |
| 大样本闭环与条件控制诊断 | `od_e5e` 扩大到 N=128000，闭环条件的 P/K 斜率仍受条件数影响；`od_e5f` 独立 PE 诊断给出 P/K 接近 -1/2 | 说明速率定理的适用条件不可省略；闭环诊断不作为定理反例 |
| 外层 Algorithm 4 全局收敛 | 论文只声明局部单步结果；外层循环仅报告有限轮和停止条件 | 不作为理论结论，不能由仿真支撑 |

## 结论

- 论文中的代数恒等式、正定性、稳定性、缩放和局部重构/辨识趋势有明确仿真证据。
- 数据驱动定理已恢复为“显式 PE/谱隙/Schur 条件下的局部 \(O_p(N^{-1/2})\) 速率”；`od_e5g` 在该条件下给出直接数值验证，闭环条件诊断则保留了适用范围限制。
- 重构误差审计现与修正后的定理一致：扰动窗口残差作为未调参项显式进入上界，仅对辨识误差常数 \(C_1\) 做独立种子标定。Humanoid 与 Microgrid 的 held-out 点均为 `48/48` 满足经验包络，最大比值分别为 `0.3948`、`0.4360`。这是有限样本证据，不是通用常数证明。
- 大样本和正交 PE 结果保留为条件/灵敏度诊断，用来说明速率定理的适用条件，不声称适用于任意闭环数据。
- 重构误差定理仍保留带常数的理论上界；当前仿真只支持经验包络，不能替代通用常数证明。
